# v0.4 验收记录

状态：2026-09-09 本地 Web 预览检查通过，尚未正式发布。Windows 构建、原生启动及双端发布仍待验证，不能据此声明完整发布验收完成。

## 本轮实测

- 依赖边界与循环检查覆盖 28 个模块；严格类型检查、静态检查、生产 PWA 构建通过。
- 18 个单元测试文件、67 项测试通过；36 项浏览器端到端测试通过。
- 包含真实离线刷新读回、连续录入不清掉下一笔输入、弹窗焦点不抢占、桌子重排不增桌和多尺寸侧栏检查。
- 使用虚构学生截图复核：默认桌号及装饰桌沿已移除，单人座位填满桌面，男女浅蓝/浅粉区分，保存提示不遮挡缩放工具。
- 本轮设计取舍：学生姓名优先，低频 CSV 导入默认收起，工具使用短标签但保留完整无障碍名称。
- 本地预览：`http://127.0.0.1:4181/?preview=0.4.0-ui`。浏览器与旧桌面应用的数据未被清空或迁移。

## 范围

保留现有平面教室工作台及功能，不新增业务模块。重构覆盖应用编排、班级生命周期、拖拽状态、领域校验、存储可靠性、样式组织、测试入口和双端发布。

## 必须通过

- 严格 TypeScript、依赖边界、无循环依赖、静态检查和生产构建。
- 座位唯一性、交换守恒、主网格与两翼对齐、不自动增桌、旧数据库迁移。
- 手动录入、拖动/点击排座、自由移动、删除桌子后学生回池、学生档案成绩录入。
- 班级快速切换、迟到响应、保存失败后重试，以及旧失败保存不能覆盖新编辑。
- 真实服务工作线程下：断网录入学生、入座、录入成绩，再断网刷新并读回。
- 375 / 768 / 1024 / 1440 等视口、独立缩放、左右侧栏展开/收起、表单操作区不拥挤。
- Web/Tauri 产物隔离、版本及提交标识一致；Windows 构建和原生窗口启动。

## 人工复核范围

使用虚构班级和学生，不访问已有教师数据。截图应记录桌面工作台、两侧收起、学生/成绩弹窗及窄屏抽屉。自动尺寸断言不能代替看图检查。

## 限制

- 完整备份、Excel 名单导入、历史记录及打印导出尚未开放，本次不将它们声明为已验收功能。
- Windows CI 的启动测试验证进程与窗口，不等于所有 Windows 硬件、显示缩放或输入法组合均已实机测试。
- 没有桌面自动更新器，用户手中的旧 EXE 不会自行变成新版本；正式版本应从同版 Release 下载。
