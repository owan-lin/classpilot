# ClassPilot 界面契约

> 面向初中班主任的高频座位管理工作台。核心任务是在一张稳定、完整的教室画布上看清并调整全班座位；导航和表单都应退居两侧。

## 视觉方向

- 关键词：教室控制台、克制、清晰、可触摸、非营销页。
- 标志性体验：进入任何班级后，视口中心始终是同一张教室画布；左右工具抽屉开合，但画布和讲台保持空间连续性。
- 字体：系统中文无衬线字体栈；标题、正文和数据仅通过字号与字重分层，不加载网络字体。
- 动效：只为抽屉开合、选中与拖动反馈服务，使用 transform/opacity；尊重 reduced-motion。
- 禁止：Hero、CTA、玻璃拟态、渐变光晕、大圆角卡片墙、装饰性文案、页面间不同的内容宽度。

## 颜色令牌

| 语义 | 颜色 | 用途 |
|---|---:|---|
| 导航蓝 | `#143f60` | 紧凑侧栏轨道与折叠状态 |
| 品牌蓝 | `#1972aa` | 主操作、当前工具、焦点辅助 |
| 工作台灰 | `#f4f7f7` | 教室地面，覆盖中央剩余空间 |
| 平面桌面 | `#f8fafb` | 普通课桌的扁平 surface，不使用木纹或厚木边 |
| 桌面边线 | `#9fc1d2` | 课桌、讲台与教室组件的结构边界 |
| 男生底色 | `#dceef8` | `data-gender="male"` |
| 女生底色 | `#f8e3eb` | `data-gender="female"` |
| 未填底色 | `#e8ecef` | `data-gender="unspecified"` |
| 主文字 | `#17324d` | 正文与数据 |
| 次文字 | `#536776` | 辅助信息 |
| 分隔线 | `#c7d4dc` | 结构边界 |

性别不能只靠颜色表达：座位、待安排列表与档案必须同时暴露“男 / 女 / 未填”文字或可访问名称。选中态使用外轮廓和角标，不覆盖性别底色。

## 桌面工作台（≥1024px）

```text
┌──────────┬───────────────────────────────────┬──────────────┐
│ 班级轨道 │          教室画布（主角）          │  工具轨道     │
│  可展开  │  班级名/状态为画布内轻量浮层       │  可展开       │
│          │  讲台与课桌保持空间连续            │  排座/教室    │
│          │                                   │  学生/成绩    │
└──────────┴───────────────────────────────────┴──────────────┘
```

- 左侧折叠后 56px，展开后约 232px；新建班级属于这里。
- 右侧折叠后 56px，展开后约 340–400px；工具导航与当前工具内容共用一个垂直槽位。
- 两侧可独立开合；中央使用 `minmax(0, 1fr)`，不出现页面级横向滚动。
- 待安排学生是“排座”工具内容，不再永久占据画布右边。
- 学生、成绩、教室设置在右侧面板内滚动，底部操作区位置一致；切换工具不能推动画布或改变页面外边距。
- 中央画布只保留一个必要的滚动容器；不得再套白色卡片边框制造双重滚动。

## 小屏（<1024px）

- 中央画布保持全屏底层；左右侧栏变为带遮罩的覆盖式抽屉。
- 抽屉必须有明确关闭按钮、Escape 关闭和正确 `aria-expanded` / `aria-controls`。
- 不允许页面级横向滚动；画布自身可平移或缩放到可操作范围。
- 焦点进入抽屉后不能被固定元素遮挡；关闭后回到触发按钮。

## 对齐与组件规则

- 所有工具面板使用同一顶部标题线、16px 内容内边距和底部操作栏。
- 图标统一使用 Lucide，轨道图标按钮命中区至少 44×44px，并有文字标签或可访问名称。
- 交互焦点清晰可见；拖动必须保留点击/键盘替代。
- 4/8px 间距系统；正文至少 14px，移动端表单输入文字至少 16px。
- 状态提示使用 `aria-live`，不新增常驻说明条。
- 画布缩放是独立的右下角 44px 命中区控件；缩放时画布内部滚动，不压缩课桌文字。
- 学生档案弹窗使用档案/成绩 tablist；成绩记录和录入表单是独立分区，弹窗自身可滚动，CTA 与字段保持至少 8px 间距。

## 样式架构契约

样式入口保持单向层次，`src/App.css` 的导入顺序就是覆盖顺序：

1. `tokens.css`：字体、语义颜色、圆角、阴影、动效、工作台几何和层级令牌，以及全局可访问性基础。
2. `shell.css`：桌面三列工作台、两条紧凑轨道、工具导航和桌面折叠状态。
3. `classroom.css`：中央画布、课桌、座位、性别辅助色、讲台和缩放控件。
4. `forms.css`：操作按钮、工具面板内容、表单、档案弹窗和状态提示。
5. `responsive.css`：`≤1024px` 的全屏画布/抽屉几何与 `≤560px` 的单列表单；仅此处定义断点布局。
6. `mobile-rail-close.css`：移动抽屉关闭按钮的固定位置与命中区。
7. `drawers.css`：移动遮罩、抽屉宿主、开合后的指针事件与层级覆盖；必须最后加载。

组件样式不得重新定义这些全局令牌的同义硬编码颜色、尺寸或层级。抽屉层级固定为：画布 `1` → 状态提示 `20` → 移动开关 `22` → 遮罩 `23` → 抽屉宿主 `24` → 抽屉面板 `25` → 关闭/工具导航 `26` → 抽屉切换按钮 `27` → 模态 `30` → 提示浮层 `40`。`prefers-reduced-motion` 中保留 `!important` 是有意的可访问性例外，用来覆盖抽屉等后置模块的动效声明。

维护规则：同一选择器只在一个模块定义基础样式；响应式模块只覆盖几何/可见性；抽屉模块只覆盖移动层叠和交互命中。座位性别底色不覆盖可读文字，选中态使用轮廓；固定元素必须为底层滚动内容预留空间。任何新增拖动视觉反馈都应使用 transform/opacity，并同步提供点击或键盘替代。

## 验收视口

- 1440×900：双侧栏同时展开，画布仍为最大视觉区域。
- 1024×768：一侧可展开，另一侧默认折叠，画布不横向溢出页面。
- 768×1024 与 375×812：侧栏覆盖式，能打开、切换、关闭，底层画布不跳位。
- 所有视口：切换排座、编辑教室、录入学生、成绩时，工具面板边界与操作区对齐一致。
